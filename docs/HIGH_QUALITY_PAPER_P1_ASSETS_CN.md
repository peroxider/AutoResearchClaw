# P1 公式、算法、证明记录和实验图

`publication_assets.py` 负责从权威研究产物构建可重算的出版内容。ManuscriptIR 写作前生成资产清单，正文渲染与最终验收使用同一清单；来源、文件或渲染器变化会使依赖稿件失效。

## 数学与算法内容

MethodSpec 的变量含义与形状、公式、训练/推理步骤、依赖关系、公式对应关系、源码符号、损失、停止条件和复杂度进入 Methods。公式只接受有界数学 LaTeX 命令集；文件读取、环境结束、宏定义、命令执行、双尖号转义和不平衡括号都会被拒绝。导出使用 amsmath/amssymb，而不是将模型提供的任意 TeX 当程序运行。

算法步骤按 MethodSpec 的依赖顺序导出，保持训练与推理区分；可选 `control_flow` 已支持显式分支/循环和共源执行图，参见[图与控制流说明](HIGH_QUALITY_PAPER_P1_DIAGRAMS_CN.md)。复杂度为源规范中的声明；代码符号映射也不证明完整语义等价，正文明确保留 `semantic_equivalence` 的实际状态。

TheoryBundle 的定义、假设、依赖、命题、原始证明文本、检查器证据和状态进入 Theory。多项式表达式由已经验证的 AST 转成数学排版，不执行表达式。未证明、已反驳、非形式化评审和精确恒等式检查分别保留，不因为能够排版就获得证明成功状态。

## 可重算实验图

每个冻结 RQ/数据集/指标/候选与基线比较生成一幅双面板图：配对种子的原始指标和候选减基线的差值。每条线/点来自完整协议中独立评估的结果 ID。缺失、无效或多余单元导致协议不完整时，禁止选择剩余成功种子画图。

- CSV 保留每个种子的基线值、候选值、带方向的差值及两个原始 result ID。
- PNG 用于 Markdown，PDF 用于 LaTeX；均由 matplotlib 程序生成。
- 零提升和负结果原样显示。分数/百分比面板使用对应指标范围，配对差值面板保留零线和明确符号。
- 图中显示的均值是已观察种子的均值，不把训练随机性当成总体抽样，不生成无依据的总体置信区间或显著性标记。
- `publication_assets/reproduce.py` 在安装相应 researchclaw/matplotlib 的环境中从已打包的原始证据重建图表。

`publication_assets.json` 保存公式/步骤/证明规范、来源摘要、每幅图的数据、输出摘要、matplotlib 版本及渲染代码摘要。文件名包含图数据与身份的内容摘要。验证时重新核算实验比较、CSV，并用确定性渲染重建 PNG/PDF 摘要；仅替换图片后再修改清单摘要仍会失败。进程内缓存只保存根据当前源规范实际渲染得到的预期摘要，不以清单里的摘要作为真值。

## 集成与验收

后续已接入 [AnalysisSpec](HIGH_QUALITY_PAPER_P1_ANALYSIS_CN.md)。冻结的 `analysis_plan` 选择配对种子图或效应汇总图；效应图保留所有源 ID、比较顺序及可用的条件种子均值区间。缺失/变化的分析契约会使资产校验失败。恒定差值或种子不足不会产生假精确区间，声明的可交换性仍需要单独审查。

`build_manuscript()` 在证据目录建立前生成/复核资产；资产清单成为稿件依赖。Methods、Theory、Results 分别插入相应的确定性内容。打包复制资产目录和复现脚本。最终验收既检查共源稿件字节，也重新验证图表数据与输出。

生成成功标记为 `rendered`，`visual_review` 仍为 `unavailable`。自动数值/标签渲染的一致性检查不等于每幅图或整稿布局已通过视觉审稿。本轮实际生成并查看了零差异测试图；没有据此给其他论文的图形或整稿授予视觉通过状态。

测试覆盖受限数学语法、恶意 TeX 转义、精确公式与算法来源、未决证明保留、全部种子/结果 ID、真实独立复算得到的负效果、零差异、缺失单元、调换方向、伪造 CSV/PNG/PDF 后重写摘要、全局绘图风格变化、稿件/打包集成。PNG 和独立图表 PDF 均实际生成；整稿 LaTeX 编译仍受本机缺少 pdflatex 限制。
